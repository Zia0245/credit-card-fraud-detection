# Credit Card Fraud Detection
Detects fraudulent card transactions on a highly imbalanced dataset using class-weighted Logistic Regression, Random Forest, XGBoost, and a PyTorch neural network, evaluated with PR-AUC. Built with Python, scikit-learn, XGBoost, and PyTorch.

Dataset: Credit Card Fraud Detection (ULB, Kaggle: mlg-ulb/creditcardfraud)
